First release.

- Record force-feedback effects from a game through a virtual wheel while
  passing them through to the real wheel (Linux: uinput and evdev).
- Play recordings back into the wheel on their original timeline, with
  speed and loop.
- Live graph of the rendered force (constant, ramp, periodic, condition
  and rumble parts) and steering position in a browser tab.
- `.ffbr` JSON Lines recording format, plus `info` and CSV `export`.
- Windows and macOS builds include the UI, demo source and file tools; a
  device backend for those platforms is not in this release.
